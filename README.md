# 学伴 · 学而思家长端管理系统

面向每日作业的非官方、自托管管理工具。目标是通过独立网页整理、查看并同步作业到学习机，无需常驻模拟器。项目与学而思无隶属或官方合作关系。

**当前支持 v3 工作台和本机草稿后端。** 桌面／移动布局、深浅／系统主题、日期筛选、作业详情、目标时长和提交要求均可使用。草稿保存到本机 SQLite，支持显式导入浏览器旧草稿。真实作业只读适配层已接入，需额外配置经授权的本机私有运输模块；支持 macOS 钥匙串与本机加密会话；公开仓库默认未连接，演示数据必须主动开启。单条文字草稿支持提交预览和明确确认，需另行配置私有创建运输；默认未启用。

支持 WebMCP 的会话浏览器可直接查询作业、创建/修改本机草稿并生成操作预览；最终提交与删除仍须家长本人在“会话操作”页确认。凭据继续只留在本机后端。使用与边界见 [WebMCP 实施与验证](docs/webmcp-verification.md)。

## 技术栈与结构

pnpm monorepo、Node.js 24、TypeScript strict、React 19 / Vite / shadcn/ui（Base UI）、Tailwind CSS 4、TanStack Query、Fastify 5、SQLite / Drizzle、WXT（Manifest V3）。React Router 管理页面与筛选地址，Zod 校验数据，GSAP / @gsap/react 提供尊重减少动态效果设置的短时动效。

```text
apps/
  web/            响应式管理端
  api/            本机 HTTP API 与静态页面服务
  extension/      浏览器扩展，独立构建
packages/
  contracts/      Zod 数据契约
  domain/         独立业务规则
  tal-adapter/    只读适配器、本机会话、Cookie 续期和响应校验
  db/             草稿仓储与版本化 SQL 迁移
openspec/         SDD 规格、提案、设计和任务
scripts/          公开内容检查
tests/e2e/       桌面及移动视口测试
```

详细边界见 [架构说明](docs/architecture.md)。

## 本机运行

需要 Node **24.22.0**（见 `.node-version`）和 pnpm **11.15.0**。SQLite 预编译模块下载不可用时需要本机 C++ 工具链。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://127.0.0.1:5173`，Vite 将 `/api` 代理到 `127.0.0.1:3000`。在单一端口运行构建产物：

```sh
pnpm build
pnpm start
```

打开 `http://127.0.0.1:3000`。默认服务只监听本机地址。显式 NAS 模式提供 HTTPS、管理认证和局域网来源限制，部署步骤见 [绿联 NAS 部署](docs/nas-deployment.md)。

### 浏览器扩展

```sh
pnpm dev:extension
# 或构建全部项目后手动加载 apps/extension/.output/chrome-mv3
```

在 Chrome 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。扩展按钮只打开本机 `3000` 端口，需先运行 `pnpm start`。生产清单无网站权限、Cookie 权限、内容脚本或后台脚本；开发时 WXT 可能注入开发工具，不应将开发包发布。

### 当前 API

| 地址                                    | 行为                                       |
| --------------------------------------- | ------------------------------------------ |
| `GET /api/v1/health`                    | 本机服务健康状态                           |
| `GET /api/v1/connection`                | 只读连接状态与本地上下文别名，不返回凭据   |
| `GET /api/v1/homework?childId=…&date=…` | 已授权孩子的指定日期作业，无会话返回 503   |
| `GET /api/v1/demo/homework`             | 明确标记 demo 的合成作业                   |
| `GET/POST /api/v1/drafts`               | 草稿列表／新建                             |
| `GET/PUT/DELETE /api/v1/drafts/:id`     | 草稿读取／编辑／删除                       |
| `GET/POST /api/v1/agent/drafts`         | 当前孩子草稿及版本；幂等创建、原子版本更新 |
| `POST /api/v1/drafts/import`            | 事务导入，冲突不覆盖，重复内容幂等         |
| `POST /api/v1/session/renewal`          | 指定扩展配对后验证并加密保存续期凭据       |
| `POST/DELETE /api/v1/session`           | 一次性配对交接／删除本机会话               |

`POST /api/v1/session/pairing` 仅允许配置的扩展后台申请短期一次性配对，不向普通网页开放。

草稿默认保存到项目 `data/drafts.sqlite`；`DATABASE_PATH` 可指定路径，测试使用 `:memory:`。数据库迁移随构建部署。浏览器旧草稿通过“导入到本机后端”按钮导入，原件保留作备份；不会自动覆盖已编辑记录。目标时长支持不限及 10、15、20、30、40、50、60 分钟，提交要求支持不限、图片、音频、视频、音频或视频。旧数据缺少选项时保持“未设置”。业务日期为 `Asia/Shanghai`。

本机数据接口拒绝外部 Host 和跨站 Origin；草稿写入还要求 `X-Local-Request: 1` 和 JSON。默认服务只监听回环地址；NAS 模式采用独立的 HTTPS、认证和精确来源边界，不直接放宽本机模式。

### 可选的本机只读连接

`TAL_READONLY_MODULE` 指向本机管理员准备的私有 ESM 模块，导出 `createTransport(ReadFailure)`，返回接收会话上下文、查询日期和 AbortSignal 的读取函数。它仅可访问用户已授权的官方读取接口，并须禁用重定向、校验响应并遵守取消信号。模块不随本仓库分发；不要把厂商私有常量、令牌或原始响应提交到 Git。

`TAL_EXTENSION_ORIGIN` 显式允许已授权 Chrome 扩展的精确来源。扩展后台可在用户点击连接后申请五分钟一次性配对，随后交接；无需人工生成文件。后台不得将配对密钥传到网页、内容脚本、URL 或持久存储。`TAL_PAIRING_KEY_FILE` 仍可用于兼容临时验证，但已消费文件不应用于长期启动配置。

可将非秘密的本机启动配置放在已忽略的 `.env.local`，构建后运行 `pnpm start:local`。该命令只在显式调用时读取此文件；普通 start 与自动测试不加载它。不要在配置中保存账号令牌。

显式配置绝对路径 `TAL_SESSION_FILE` 可启用持久模式，例如将路径设为项目 `data/session-vault/session.enc`。密文使用 AES-256-GCM，目录 0700、文件 0600；随机加密密钥保存在当前 Mac 登录钥匙串的 `com.xueersi-admin.session-v1` 项，绝不与密文一同明文落盘。首次可能需要本人解锁钥匙串；不支持的系统或不可用钥匙串会明确失败。不要备份原始令牌或将私有 data 目录提交 Git。

持久模式不再按本地 15 分钟时限清除会话，正常关闭及重启后恢复。只有官方成功读取才标记会话已验证。设置页的“断开并删除本机会话”删除密文并取消在途请求；加密密钥可保留供下次连接使用，其中不包含账号令牌。未配置保险箱时仍使用原 15 分钟内存模式。

运输模块可选导出 `createRefresh(ReadFailure, createCookieRefresh)`。第二个参数是经过合成测试的认证运输工厂：由私有模块提供固定 HTTPS 认证地址、非敏感请求头和已验证的认证拒绝码；HTTP 客户端不能指定目的地。返回函数接收会话与 AbortSignal，产出 `{ token, renewal }`。`renewal` 包含认证设备上下文、Cookie（可选到期时间）及下次检查时间；与令牌一同加密、原子保存。Cookie 只送认证端点，不传给作业读取运输，不跟随重定向。

配置续期运输并经授权交接 Cookie 后，读取时每五分钟至多进行一次常规认证检查，空闲时不轮询；鉴权失效合并续期，最多重试一次作业读取。允许官方返回相同令牌，按后续实际读取判断有效性；轮换 Cookie 同步保存。网络错误保留会话并退避三十秒；官方明确拒绝或重试仍失效时清除无效会话并提示本人登录。旧会话不含 Cookie 时保持原读取能力，界面不会误报已启用自动续期。

Cookie 交接仅允许配置的扩展来源、`X-Local-Request` 和一次性短期配对密钥；先验证当前孩子及设备只读访问，再替换加密会话。普通官网会话交接接口不接受 Cookie。首次引导结束后可以撤销扩展临时 Cookie 权限，后端使用已保存凭据独立运行。公开的 WXT 扩展仍是打开本机网页的入口，私有引导验证器不随开源仓库分发。**不能保证永久免登录；真实自然失效恢复与合成失效测试需分别记录。**

交接可包含 `childName` 与 `deviceName`，工作台仅显示所选对象的名称及本地别名，不返回原始标识和凭据。只有一个授权上下文，不表示可切换整个家庭。当前公开 WXT 扩展仍为启动器，研究用验证器独立保存在本机，不捆绑到开源发布。

## 规格与质量

使用 **OpenSpec SDD + TDD**：先提案和可验收场景，再写失败测试，实现最小通过，最后重构和回归。当前能力以 [`openspec/specs/`](openspec/specs/) 为准，已完成变更保存在 [`openspec/changes/archive/`](openspec/changes/archive/)，工作流指令位于 `.agents/skills/`。收尾映射与验收边界见 [发布收尾记录](docs/release-closeout.md)。

参阅 [贡献约定](CONTRIBUTING.md)、[测试记录](docs/testing.md) 和 [安全与数据边界](SECURITY.md)。CI 只使用合成数据，不需要真实账号。

## 当前能力与后续边界

已实现后端草稿持久化、加密会话及 Cookie 按需续期、作业总览与报告、WebMCP 查询和草稿工具、单条/批量确认同步、未完成作业确认删除，以及 NAS 局域网部署。真实提交和删除仍由用户在网页确认，WebMCP 仅生成预览。

单条首单官方接受、回读及 T6 显示已完成验收，设备显示和选项依据用户实机反馈。NAS 重启后的会话与只读恢复、网页 WebMCP 及用户手机访问已验证。自动测试只使用合成数据；真实删除、批量写入、视频报告和官方会话自然到期恢复的验收边界分别见验证记录，不因规格归档自动视为通过。

后续可完善产品化扩展交接、群消息整理、图片附件上传，以及长期观察自然失效恢复。私有官方运输及引导验证器不随公开仓库分发，图片作业上传尚未开放；现有提交图片要求指孩子完成后的提交类型。

### 草稿确认同步

从草稿选择「同步到学习机」，生成五分钟有效预览，核对孩子、设备、全文、作业类型、日期、时长和提交要求后，再点击「确认提交这条作业」。新建类型为当前学科的「其他」，正文最多 300 字；日期为今天至未来 30 天。旧草稿未设置时长或要求时必须补齐。

`POST /api/v1/sync/preview` 仅预检，`POST /api/v1/sync/confirm` 要求一次性密钥和明确确认。`GET /api/v1/sync/records` 展示持久结果。私有模块可导出 `createWriter()`，提供只读 `prepare` 和单次 `submit`。未配置时预检失败，读取不受影响。

同步结果中「官方已接受」不等于学习机已经收到。超时、断网或进程退出留下的发送记录视为结果不确定，相同目标和内容禁止重发；应先在学习机核对。明确业务拒绝后可重新预览再确认，写入请求永不自动重试。记录保存在本机 SQLite，保留草稿原件；不要删除同步数据库来绕过防重。

### 任务总览、报告与删除

`/calendar` 提供独立整月总览与全屏模式，每日显示任务数、完成数、剩余数；过去日期未完成标为有遗漏，无任务不计为全部完成。桌面日格直接显示学科、作业摘要和状态，最多三条，超出以「+N 项」展开；手机保留七列，多项显示「+N」，点击可在当前页阅读当天全部作业。支持月份切换、日期下钻、桌面/手机和深浅主题。月份统计使用官方当前记录，不能恢复已删除的任务。

`GET /api/v1/homework` 可选 `endDate`，区间上限 42 天；`GET /api/v1/homework/report` 接收 `childId`、`date`、`id`，只允许当前孩子列表内已完成作业。私有模块可导出 `createReportTransport()`，归一化图片、音频、视频及过期状态；媒体来源须由私有模块白名单校验，不转发认证头或 Cookie，不自动播放。

未完成作业可通过 `/api/v1/homework/delete/preview` 预览，随后使用一次性票据调用 `/confirm`。私有写运输另需实现 `prepareDelete`。确认前后都核对会话、目标、内容和状态；取消无官方写入，写入前持久防重，不确定结果不自动重试。完成报告与删除的公共测试仅用合成数据；实际删除验收仍须明确确认具体作业。
