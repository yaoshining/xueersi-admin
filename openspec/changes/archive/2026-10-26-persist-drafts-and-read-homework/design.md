# Design

## Context

React 页面使用浏览器存储，已有 Drizzle 草稿表仅支持创建和按 ID 查询。Fastify 目前只有演示读取。此前本机只读验证采用官网会话、所选孩子及设备上下文，凭据仅驻留内存。

## Goals / Non-Goals

**Goals:** 使用共享 Zod 契约、SQLite 迁移、同源草稿 CRUD、显式旧数据导入和 React Query；将既有验证运输逻辑隔离在本机私有模块，公开适配层保证只读与安全错误。

**Non-Goals:** 官方写入、远程部署、持久化凭据、多用户鉴权、学习机内容关联。

## Decisions

- 草稿新增可空目标分钟与可空提交类型。null 表示旧草稿未设置，0 / none 表示用户选择不限。截图及已保存的官方表单代码确认时长 10、15、20、30、40、50、60，提交不限、图片、音频、视频、音频或视频。
- 草稿新建冲突返回 409，更新只针对已存在 ID。导入使用事务，不覆盖同 ID 不同内容，保留浏览器原件作为备份；避免自动迁移覆盖其他浏览器的新编辑。
- API 默认测试库内存化，启动服务才配置忽略目录中的 SQLite 文件；迁移目录显式传入，构建产物一并复制迁移。
- 本机接口校验 Host、Origin 与 JSON 请求；拒绝跨站读取及写入，不启用通配 CORS。会话交接独立使用短期一次性配对密钥，不通过管理端返回令牌。会话断开/过期/服务关闭立即清除引用；拒绝上下文不匹配的查询。
- 官方协议私有模块只导出读取函数，配置由启动环境提供路径；公开适配器负责会话、日期范围、模式和响应校验，测试注入合成运输层。管理端真实作业查询与演示查询使用独立缓存键，错误不显示旧数据。
- 页面路径变化回到页首，日期切换不重置滚动；保留现有轻量小书 SVG，不因看不到而新增重型 3D 渲染。

## Risks / Trade-offs

- [官网会话可能已失效] → 显示需重新连接；实际验证需要用户在官方页面登录时再请求操作。
- [上游接口或字段改变] → 返回安全结构错误，不猜测成功，不透传上游响应。
- [开源部署缺私有协议模块] → 默认断开，可运行演示与本地草稿；不会捆绑私人研究材料。
- [旧草稿缺字段] → 保留未设置，不自动假定用户的提交要求。

## Migration Plan

增加可空列并测试旧数据库迁移、关闭重开。浏览器显示显式导入入口；导入冲突整批回滚。回退应用前先备份 SQLite，新列不删除旧内容。凭据在停止进程后消失，无令牌数据库迁移。
