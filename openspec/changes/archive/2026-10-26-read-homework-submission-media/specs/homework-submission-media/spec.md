# Spec Delta

## Purpose

让家长在会话中安全读取当前孩子已完成作业的图片和音频，以便核查提交内容；媒体经本机服务按需读取，凭据及官方签名链接不向会话暴露，也不改变作业状态。

## ADDED Requirements

### Requirement: 会话读取提交媒体

系统 SHALL 为可用图片和音频提供临时附件引用，工具按引用读取单个附件并返回类型、MIME、字节数和媒体内容，不要求打开详情页。

#### Scenario: 读取图片与音频

- **WHEN** 当前授权孩子的已完成作业包含图片或音频，调用者读取详情再使用附件引用
- **THEN** 返回对应原始媒体内容及元信息，不暴露官方链接、账号或设备内部标识，且没有官方写入

#### Scenario: 不可用附件

- **WHEN** 附件过期、不支持、超过大小限制或下载失败
- **THEN** 返回安全错误或不可用状态，不声称已经检查内容，不返回上游响应正文

### Requirement: 附件读取隔离

系统 MUST 校验上下文和作业所属关系，引用有期限且绑定报告附件，不允许任意地址输入；演示模式不能读取真实附件。

#### Scenario: 上下文或报告变化

- **WHEN** 账号、孩子、设备发生变化，引用过期，报告附件变更，或传入未知字段
- **THEN** 拒绝读取；读取过程中发生变化或取消也不能返回媒体

#### Scenario: 安全下载边界

- **WHEN** 报告地址指向本机/内网、重定向、不受支持媒体或超过 16 MiB
- **THEN** 拒绝下载或终止读取，不转发登录凭据，不将媒体缓存到磁盘

### Requirement: 保留确认边界与合成验证

系统 SHALL 保留真实提交、删除的网页本人确认；测试只使用合成图片和音频。

#### Scenario: 媒体工具调用

- **WHEN** 在桌面或移动网页使用媒体工具
- **THEN** 不产生草稿变更、作业提交或删除，媒体结果标为不可信输入
