# Design

## Context

现有草稿保存在 SQLite，单条包含孩子标识、学科、日期、正文、目标时长和提交要求；没有作业类型字段。当前仅有已授权孩子/设备一组上下文。官方前端使用批量编辑端点创建（新增 id 为 0），正文上限 300；时长和资源要求已有确定映射。

## Goals / Non-Goals

**Goals:** 单条草稿先预览再确认提交，记录成功/失败/不确定结果，保留草稿原件。

**Non-Goals:** 无确认自动批量发送、图片上传、编辑官方作业、删除已完成作业、声称服务端接受等于真机收到。

## Decisions

- 单条预览只接收 draftId，服务端读最新草稿；必须与当前授权孩子一致，时长/提交要求不可未设置，正文 1–300 字符，日期为今天至未来 30 天。私有预检查询官方类型与设备能力，仅采用明确的普通作业类型并在预览显示，不隐式关联 AI 内容。
- 生成五分钟有效的一次性票据，包含随机 ID/确认密钥、草稿内容快照、目标显示名称、会话 ID 与目标指纹；密钥仅哈希留内存，不写入日志。预览和提交分离路由，确认请求必须明确 confirmed=true。
- 预览令牌不持久化，重启必须重新预览；同步结果持久到新 SQLite 表。内容指纹包含孩子/设备/日期/所有表单值；不同草稿同内容也防重复。创建不可逆副作用前以事务占用指纹并记 sending，崩溃后此状态解释为 unknown，禁止自动重发。
- 确认后再次检查草稿快照、会话和目标，先执行只读认证检查/必要续期，再调用单次写运输。外部请求开始后超时/断开/网络错误均记 unknown；只有明确的业务拒绝才记 failed。所有状态均展示，不自动重试；已成功/不确定指纹阻止重复，明确拒绝可重新预览再确认。
- 私有 prepare/submit 工厂固定官方端点及字段映射；凭据不存同步日志、不传前端，Cookie 不传写运输。预览提供外部类型标签，私有原始 payload 仅内存留存；submit 不接受来自网页的任意 payload 或目的地。
- Web 使用现有 Card/Button/Alert/Badge，独立确认页面清楚列出孩子、设备、类型、日期、全文、时长和要求；按钮明确“确认提交这条作业”。取消只丢票据。演示模式不能预览或提交真实作业。
- 首次验收仅准备真实预览并向用户展示；本轮不调用确认端点。用户之后在页面明确点击确认或在聊天确认具体预览后才执行。

## Risks / Trade-offs

- 官方端点未进行真实创建验收 → 静态来源与合成请求测试覆盖映射，首单等用户确认，不能预先宣称真机成功。
- 缺少服务端幂等协议 → 持久占用指纹并保守保留 unknown，优先避免重复。进程正常关闭也不把不确定结果改为失败。
- 本机草稿可编辑，预览可能过时 → 提交前重新核对；会话重连使旧票据失效，Cookie 日常轮换不改变确认目标。
- 官方显示资源要求依赖设备版本 → 预检能力不足时明确拒绝，不静默降级。

## Migration Plan

新增同步日志表，不更改现有草稿。未配置写运输时只读仍可用，预览返回未启用。部署后仅准备预览；回滚移除写运输配置保留同步日志，避免丢失重复保护。

## 归档前修正：回读详情

首次实机验收后发现公开作业响应只保留了内容和状态，详情也仅展示科目、日期和状态。补齐目标时长和提交要求的回读映射与详情字段；回读时长保留官方非负整数，不受创建表单的预设选项限制。缺失字段保持未知，资源类型仅映射已知枚举，未知值显示「未提供或暂不支持」，不从本机草稿回填官方信息。

## 归档前补充：删除与完成报告

- 删除预览绑定当前会话、孩子、设备和官方作业内容快照，五分钟有效、一次性密钥。确认时重新只读获取并核对状态仍未完成；当前列表中不存在的 ID 不得调用详情或删除。使用独立 SQLite 删除记录先占位再单次发送，结果未知禁止自动重试。
- 删除预览显示作业全文、日期、孩子、设备、时长和提交要求，并说明不可恢复。取消不写入官方。成功后重新读取列表；“官方接受”与“回读已移除”分别表达。
- 详情运输只接收已授权目标中的作业 ID，固定官方详情入口，复用只读认证准备。只返回归一化报告附件，不传原始响应。图片支持查看原图，音频/视频使用原生可访问控件，不自动播放；失败、无附件及官方标记过期分别呈现。
- 附件地址仅接受 HTTPS 且来自私有模块认可的官方媒体域名；不转发认证头、Cookie 或页面 Referer。附件链接不持久到公开代码或删除记录。测试仅使用保留示例域名及合成数据。
- 本轮真实检查仅回读；没有用户对具体作业的删除确认，不调用真实删除。
