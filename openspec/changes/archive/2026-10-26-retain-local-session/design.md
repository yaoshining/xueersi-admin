# Design

## Context

当前适配器将令牌保存内存 15 分钟，close 与 disconnect 共用清理。私有扩展已能取得所选孩子昵称和设备型号，但未传给后端。已保存官方 SDK 存在状态检查及心跳，未找到已验证的刷新令牌协议；不把状态检查当成令牌续期。

## Goals / Non-Goals

Goals：会话本机持久化、可靠失效状态、可撤销、无重复配对文件操作、显示所选上下文。
Non-Goals：官方写入、远程部署、密码保存、绕过验证码、宣称令牌永不过期、枚举未授权家庭成员。

## Decisions

- 使用 Node AES-256-GCM 加密版本化会话文件，随机 IV，认证版本信息，0600 原子替换；目录 0700，拒绝符号链接及过宽权限。macOS 钥匙串保存随机密钥；通过标准输入创建，避免密钥出现在命令参数。测试注入密钥。拒绝将密钥与密文同目录明文保存的替代方案。
- 适配器注入同步保险箱，明确 shutdown 仅清内存、disconnect 删除磁盘。只有配置保险箱才长期保存；未配置继续兼容原 15 分钟模式。恢复后标记尚待验证，下一次成功读取标记已验证。
- 可选 refresh transport 接收当前会话与 AbortSignal，仅返回新令牌；鉴权失败触发 single-flight，成功原子保存，最多重试一次，失败退避 30 秒；所有结果绑定原会话引用，断开或账号切换后丢弃晚到结果。真实运输未提供 refresh 时明确需要重新登录。
- 配对申请路由只接收指定扩展 Origin 与专用头，生成内存短期一次性密钥；不允许官网页面直接申请。既有文件配对入口兼容，但持久连接重启不要求该文件存在。
- 名称作为交接元数据加密保存，连接响应返回名称和稳定别名；只显示交接选中的一个上下文，不假装已获得整个家庭的切换能力。
- 设置页显示保存方式、验证状态、续期能力和重新登录提示；断开删除会话，清除真实查询缓存。网络问题不伪装成注销。

## Risks / Trade-offs

- 官方可能撤销登录 → 无已验证刷新能力时仍需本人官网登录，持久化解决本地人为失效，不能保证永久免登录。
- 钥匙串首次访问可能要求用户授权 → 明确失败，不把凭据保存为明文；真实首次交接仍需用户操作。
- 密文和同一用户下运行的后端均在本机 → 防止误提交及静态文件泄漏，不声称抵御已完全控制同一系统账号的程序。
- 会话恢复只表示可尝试读取 → 使用验证状态区分真正读取成功。

## Migration Plan

新增显式持久配置，既有内存会话不能从外部偷偷导出，升级后重新交接一次。断开可删除会话，取消配置可回滚内存模式，草稿数据库无需迁移。
