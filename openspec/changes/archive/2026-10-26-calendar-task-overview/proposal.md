# Proposal

## Why

家长需要整月全屏总览，快速发现哪天全部完成、哪天遗漏及每日任务数量；现有单日列表不能承担这个职责。

## What Changes

- 新增独立任务总览入口、月历与全屏模式，保留桌面/移动及深浅主题；全屏内容超出视口时可纵向滚动至月末。
- 日格直接显示学科、作业摘要和完成状态，桌面超出部分显示剩余数量；手机多项用数字聚合，当前页展开完整当天清单。
- 日格显示总数、完成数和剩余数；过去日期未完成标为有遗漏，今天/未来标为待完成，空日不计为全部完成。
- 点击日期进入当天作业，月份切换和返回本月；读取整个自然月，错误不伪装为空数据。

- 优化月历排版和语义状态配色：紧凑统计区、明确完成进度、安静空日及易读摘要，保持七列和全屏滚动。

## Capabilities

### New Capabilities

- `task-calendar`: 月度任务汇总、遗漏识别、全屏浏览与日期下钻。

### Modified Capabilities

无。

## Impact

Web 新月历页面、导航、统计模型及只读日期范围查询；无官方写入，无额外凭据存储。
