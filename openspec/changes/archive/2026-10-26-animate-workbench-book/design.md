## Context

现有小书是静态 SVG，GSAP 只负责页面淡入；按钮与小书共用松散的 flex 布局。

## Goals / Non-Goals

目标：标题附近可识别的立体翻页、小视口稳定布局、渐进增强与可访问回退。
非目标：改变 v3 信息架构、加入外部设计账号、修改账号或官方作业数据。

## Decisions

- 标题与小书组成独立组，操作容器单独排列。
- GSAP 驱动局部书页的 CSS 3D 变换；作用域 ref 与 useGSAP 负责销毁。
- Shaders 按需加载，仅增强视觉；WebGPU 不可用或初始化失败时保留 DOM 小书。
- 系统减少动态效果、文档隐藏和离屏均停止循环；不影响点击与键盘导航。

## Risks / Trade-offs

WebGPU 可用性与渲染成本存在平台差异，因此 GPU 层不能承担书的基本可见性。动画组件采用懒加载以避免影响其他页面。

## Migration Plan

无需数据迁移；可回退单独的小书组件和标题样式。
