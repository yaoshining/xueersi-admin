# Design

## Context

动机见 proposal.md。隔离进程检查通过，长期运行进程此前失败；诊断恢复时容器已重启，新进程也通过。历史状态已经消失，不能据此确认缓存、认证或运输初始化的根因。

## Goals / Non-Goals

本次明确区分适配器的列表读取、配置准备、超时及会话变化，并保持所有防重规则。不猜测私有协议、不增加写入重试、不通过重启自动掩盖异常。

## Decisions

- 适配器导出有限 PrecheckFailure，错误文本仅为静态错误码；公开 API 只识别该类，不信任任意异常的 code 属性。
- 只读列表和配置准备分阶段包裹；已有超时控制器、会话校验保留。提交闭包仍沿用现有语义，写入错误不转为预检错误。
- 页面列出安全中文消息。通用未知异常保留原兜底，防止暴露官方响应。
- 列表运输明确 ECONNRESET 时最多重读一次，不因此续期或断言授权失效。其他普通异常不触发该分支。网络重读和明确过期的一次续期分别计数，合计最多三次读取。持续重置保留会话。真实提交/删除绝不自动重试。

## Risks / Trade-offs

历史进程无法取证 → 明确记录局限；新增阶段码便于下次定位。配置失败可能涵盖多个私有步骤 → 仅描述已知边界，不伪造更细分类。新增提示不等于根因修复 → 真实同步前重新回读，结果不确定立即停止。

## Migration Plan

运行合成回归、pnpm check 和页面端到端测试；只更新本项目公开构建产物并重建容器，保留旧镜像和数据。部署后只读恢复并查重，再按用户具体授权提交。诊断调试口和临时文件必须清理，官方数据不进入公共证据。

## 诊断补充

NAS 独立进程连续三次观测到列表连接重置；首次旧/新令牌对照结果不同，但追加交替对照两种令牌均连续成功，Cookie 认证明确成功。当前没有本项目 Mac 监听服务，仅一个 NAS 容器。证据支持间歇性读取连接故障，不足以确认授权过期或网络设备的具体原因。新增恢复仅针对连接重置，不把 TCP 重置等同于官方明确过期。
