# Proposal

## Why

已确认的 Figma v3 需要落地为可操作的 Web 前端。当前首页仍是初始化演示页，缺少每日安排、详情、响应式导航和主题偏好。

## What Changes

- 按 Figma 可编辑 v3 实现桌面作业工作台、移动列表和详情，采用森林绿语义色与深浅主题。
- 保留默认未连接、显式进入演示的边界；日期、孩子切换、详情与返回可操作。
- 主操作提供本浏览器草稿整理、校验、保存及查看；明确草稿未发送到学习机。
- 提供同步记录、家庭与设备、设置入口与诚实的未接入状态；主题支持浅色、深色、跟随系统及本机记忆。
- 复用现有 shadcn/Base UI，补齐官方表单、选择和切换组件。GSAP 仅用于短时进入动效，尊重减少动态效果。

## Capabilities

### New Capabilities

- `homework-workbench`: 响应式作业列表、日期及孩子筛选、详情、草稿与未接入边界。
- `theme-preference`: 语义化深浅主题、系统跟随、本地偏好及减少动态效果。

### Modified Capabilities

无。现有初始化变更的断开连接与隐私边界继续保留。

## Impact

主要修改 apps/web；新增前端单元测试与 Playwright 行为、响应式验收。沿用已有只读演示 API，不增加官方接口、令牌存储或真实同步写入，不修改浏览器扩展。图形使用 Figma 小书页 SVG；本轮以已批准静态矢量为准，不新增运行中 Shader。
