# Design

## Context

现有 ReadonlyTalAdapter 已有单次认证失败重试、并发合并、断开取消和加密保险箱；实际运输模块尚未提供 refresh。官方 Cookie 对照已成功，但响应 expire 并非已证实的作业令牌寿命。

## Goals / Non-Goals

**Goals:** 延续本机保险箱和只读适配器，独立于浏览器保持认证；兼容不含 Cookie 的旧保存格式。

**Non-Goals:** 后台无限心跳、绕过官方验证码、远程部署、Android 原生认证还原及任何作业写入。

## Decisions

- 会话增加可选 renewal，包含 deviceId、受大小限制且拒绝头注入的 Cookie 数组、Cookie 到期时间、nextCheckAt；整体 AES-GCM 原子保存，沿用钥匙串密钥。普通旧会话仍可读取。
- 独立 POST /api/v1/session/renewal 只接受指定扩展 Origin、X-Local-Request、一次性短期配对密钥。依附当前会话，先换取令牌并验证当前孩子/设备只读权限，再提交；失败不覆盖原会话。正常官网交接不能附带续期凭据。
- 每次读取时，若已到 nextCheckAt 则先更新（固定五分钟检查间隔，不把 expire 当作令牌寿命）；认证失效时强制合并续期后只重试一次。无请求时不常驻轮询。
- 官方认证运输目标在私有模块固定；公共可测试工具只接受启动时配置，不接受 HTTP 提交的 URL。拒绝重定向，Cookie 只发认证端点，不传作业域名。更新仅接收原 Cookie 名、匹配域/路径的 Set-Cookie，并处理删除和过期。
- 允许官方返回相同令牌；凭据有效性由后续只读请求判断。令牌和轮换 Cookie 必须同次原子保存，保存失败保留旧快照并报可重试错误。
- 网络、超时、协议异常退避三十秒且不清凭据；明确认证拒绝或再读仍失效才断开并提示登录。关闭/断开/重新交接使在途响应无效。
- HTTP 状态、错误和日志不包含凭据；设置页说明自动续期仅在使用时执行。演示模式不调用真实接口。

## Risks / Trade-offs

- Cookie 未来被官方撤销 → 不承诺永久登录，明确拒绝后提示本人登录。
- 官方未给出明确作业令牌寿命 → 定期间隔只控制检查频率，真实过期用合成测试验证，现场只声明实际观察结果。
- 轮换之后磁盘不可写 → 不使用未保存候选，保留旧快照并报告临时失败，后续允许重新登录。
- 扩展新增 Cookie 访问 → 仅官方认证域名，凭据走后台到回环服务；首次交接后可移除临时引导权限，已加密保存的 Cookie 继续独立工作。

## Migration Plan

旧保险箱无需转换；先部署兼容代码，再交接 Cookie、关闭官网并重启服务验证。回滚前通过本机断开功能清除新增凭据，避免旧严格 schema 无法读取新增字段。公共仓库不包含私有运输配置和真实数据。
