# Spec Delta

## Purpose

让家长在本机工作台区分待同步草稿和已经成功提交的作业，通过多选与统一预览减少每日重复操作，同时维持逐条持久防重、本人确认和部分失败可核对的安全边界。

## ADDED Requirements

### Requirement: 草稿分类和历史兼容

系统 SHALL 将与成功同步快照一致的草稿排除出默认待同步列表，并在独立已同步列表展示成功摘要；旧同步记录和服务重启后行为一致。

#### Scenario: 成功后归类

- **WHEN** 一条草稿已有 accepted 记录
- **THEN** 默认草稿列表不再展示该版本，已同步列表保留正文、日期、时长、要求、孩子及设备，且不得声称真机已接收

#### Scenario: 失败或内容修改

- **WHEN** 作业明确失败，或成功后的草稿内容已修改
- **THEN** 仍可在待同步列表选择新预览；未知结果对应版本显示待核对且禁止再次同步

### Requirement: 批次选择及完整预览

系统 SHALL 支持当前孩子的草稿选择和全选，每批 1–20 条；预览包含每条完整正文、日期、目标、时长和提交要求，预览及取消 MUST 不产生真实写入。

#### Scenario: 无效选择

- **WHEN** 批次为空、超限、重复 ID/内容、混合孩子、包含已同步或选项无效的条目
- **THEN** 拒绝整批预览且不写入官方

#### Scenario: 响应式与演示边界

- **WHEN** 在桌面或手机、深浅主题中选择多条草稿
- **THEN** 可通过键盘和触摸完成选择及核对，无横向溢出；演示模式禁止真实预览和发送

### Requirement: 一次本人确认和持久防重

系统 MUST 在本人网页确认整批预览后才发送，每次确认绑定原批次快照、会话、孩子、设备和有效期限；重复确认不得重发。

#### Scenario: 确认前变动

- **WHEN** 任一草稿变更或删除、会话/设备改变、预览过期或取消
- **THEN** 整批拒绝且不发送任何条目，需要重新预览

#### Scenario: 部分失败或结果不确定

- **WHEN** 顺序发送中有一条明确失败、结果不确定或状态失效
- **THEN** 停止后续发送，显示每条成功、失败、待核对或未发送；不得自动重试已接受或不确定项

#### Scenario: 刷新与服务退出

- **WHEN** 网页中断或服务重启
- **THEN** 已写入的每条结果可在同步记录回读，发送中视为待核对并持续防重；内存票据失效
