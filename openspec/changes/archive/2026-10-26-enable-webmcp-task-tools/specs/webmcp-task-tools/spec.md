# Spec Delta

## Purpose

使家长在当前会话通过网站的结构化工具查询作业、创建和修改本机草稿、生成任务操作预览，同时保持本机凭据保管、上下文隔离和本人网页逐次确认的边界。

## ADDED Requirements

### Requirement: 页面工具生命周期

系统 SHALL 按实际浏览器能力注册工具，路由切换不重复注册，卸载后撤销；不支持时网页仍可用。

#### Scenario: 注册与清理

- **WHEN** 页面挂载、切换路由或卸载
- **THEN** 工具各注册一次，离开页面后撤销，未完成读取被取消；失败不影响普通页面

### Requirement: 作业查询和数据最小化

系统 SHALL 提供上下文、作业列表/详情和月度汇总查询，限制当前授权孩子与42天区间，MUST 不返回凭据、确认密钥或附件 URL。

#### Scenario: 非法输入与旧上下文

- **WHEN** 输入包含未知字段、非法日期、超范围或旧上下文引用
- **THEN** 返回固定安全错误，不执行后续操作；演示模式不访问真实接口

#### Scenario: 查询内容

- **WHEN** 查询作业与完成报告
- **THEN** 返回需要的摘要、目标时长、提交要求和附件类型，正文标记为不可信内容，任务以临时引用表示

### Requirement: 本机草稿幂等与并发

系统 SHALL 支持含目标时长和提交要求的本机草稿创建/修改，不自动同步官方。

#### Scenario: 重复创建与冲突

- **WHEN** 相同 requestId 再次创建，或用旧版本修改草稿
- **THEN** 相同内容创建返回原件，不同内容或旧版本更新拒绝，现有内容不被覆盖

### Requirement: 操作预览与本人确认

系统 SHALL 允许工具生成提交或未完成作业删除预览，最终真实写入 MUST 只由用户在网页逐次确认；工具不得暴露最终写入能力。

#### Scenario: 预览取消与失效

- **WHEN** 工具生成预览、取消或预览过期
- **THEN** 不产生官方写入，页面显示具体孩子设备和完整内容；取消和过期后不能确认

#### Scenario: 本人确认与结果

- **WHEN** 用户确认预览或内容/目标在确认前变化
- **THEN** 复用后端单次票据及快照校验，变化则拒绝；成功/失败/未知分别显示，未知不自动重发

#### Scenario: 工具尝试越权

- **WHEN** 工具输入携带 confirmed、任意 URL、secret 或调用未定义工具
- **THEN** 拒绝调用，不能跳过网页本人确认
