# Design

## Context

既有作业读取、草稿和同步/删除预览接口已存在；最终写入使用短期单次票据并校验快照与目标。普通草稿 PUT 没有版本要求，需要为工具单独提供严格的原子更新接口。

## Goals / Non-Goals

本轮交付查询、草稿创建修改、任务预览以及本人网页确认。非目标：代理最终写入、批量删除、远程 MCP 服务、任意网络/脚本工具、导出认证资料。

## Decisions

- React 页面外壳挂载工具，路由切换不重复注册；优先 document.modelContext，兼容有 registerTool/unregisterTool 的旧 navigator 实现。无能力时展示不可用状态，不更改浏览器安全设置。注册失败撤销已注册项；组件卸载撤销工具并中止请求。
- 工具输入以 contracts 中严格 Zod schema 校验并生成 JSON Schema。日期最大42天、列表分页、正文上限5000；所有非上下文工具要求 get_task_context 返回的临时 contextRef。会话/孩子/设备或演示模式变化拒绝旧引用，重新获取上下文。
- 控制器只发起白名单同源请求。连接、作业和预览结果按字段挑选；任务以临时引用代替官方 ID，返回的附件只有类型和可用状态，无 URL。会话令牌、Cookie、sessionId、确认 secret 不进入模型结果或日志。作业正文作为不可信数据返回，不能变成工具指令。
- 创建草稿采用调用者 requestId 派生确定的本地草稿 ID，相同内容重复创建返回原件，不同内容冲突。修改要求最新内容快照版本；SQLite 事务校验版本并写入，已有 UI 修改也使旧快照失效。后端再核对当前孩子，不放宽 Host/Origin/请求头保护。
- 查询后工具生成预览，控制器保留完整票据，导航会话操作页，仅返回脱敏摘要、有效期和 actionRef。最多一条待确认操作；禁止另一次工具调用覆盖用户正在核对的内容。页面刷新丢失密钥，用户必须重新生成预览。
- 网页确认按钮调用既有 confirm 接口；工具清单无 confirm/submit/delete 写入工具，也无 generic fetch。按钮的存在不是安全隔离证明，代理不可代点。过期、取消、连接/草稿变化按现有后端重查拒绝；发送结果未知禁止自动重试。取消和状态工具不返回票据。
- 工具调用可取消。纯读取结果取消后不返回，写草稿前已取消则不发送；写请求发出后取消不代表回滚，使用同 requestId 或重新读取核对。所有变更刷新对应 React Query 缓存。

## Risks / Trade-offs

WebMCP 标准和宿主 API 正在变化，自动测试注入模拟 modelContext 只证明适配层逻辑，必须单独记录当前会话浏览器的真实发现与调用结果。工具查询内容会进入本会话模型，凭据仍不离开本机后台。上下文引用与待确认状态只在当前页面有效。

## Validation

Red → Green：契约、凭据隔离、非法目标、幂等/冲突、过期/取消/重复操作、清理生命周期；浏览器确认前断言官方 confirm 请求为0，用户点击的合成测试可验证最终请求。真实验收仅执行授权查询和本机合成草稿，不提交或删除真实任务。
