# nas-deployment Specification

## Purpose

通过显式配置将服务及经授权重新加密的会话部署到家庭 NAS，在局域网 HTTPS 下维护草稿、作业查询及用户网页确认操作。

## Requirements

### Requirement: 显式局域网认证模式

系统 SHALL 保持默认本机访问模式；NAS 模式 MUST 使用 HTTPS 并限制 Host、Origin 与来源网段。默认使用密码认证，用户明确选择 LAN 免登录模式时才可跳过密码认证。

#### Scenario: 未授权或跨站请求

- **WHEN** 密码模式请求缺少管理认证，或任意 NAS 模式请求来自非允许网段、伪造 Host 或跨站写入
- **THEN** 请求被拒绝且不泄露凭据、孩子、作业或静态管理页面

#### Scenario: 配置不完整

- **WHEN** NAS 缺少证书、独立密钥或合法局域网配置，或密码模式缺少管理密码摘要，或认证模式取值未知
- **THEN** 服务拒绝启动且不降级到无认证 HTTP

#### Scenario: 已认证使用

- **WHEN** 家庭用户通过受信任 HTTPS 和管理认证访问
- **THEN** 可以查询、创建本机草稿与预览，真实提交和删除仍需网页确认

#### Scenario: 用户选择局域网免登录

- **WHEN** 配置显式设置为 `NAS_AUTH_MODE=lan`，请求来自允许网段和正确 Host
- **THEN** 页面和同源 API 不发送 Basic 登录挑战，允许查询与管理草稿；保留来源检查、跨站限制和真实提交/删除的网页确认流程

#### Scenario: 从聊天或导航网站进入页面

- **WHEN** 允许网段的用户从外站发起 GET/HEAD 顶层文档导航，导航目标是已知前端路由，Host 正确且满足当前认证模式
- **THEN** 返回前端页面而非 `ORIGIN_DENIED`，页面随后可以使用同源 API；不为外站开放 API 读取、跨站写入、嵌入或凭据交接

#### Scenario: 伪装导航或嵌入请求

- **WHEN** 跨站请求目标为 API，或是 iframe、资源、Fetch/XHR、预检或修改方法
- **THEN** 继续拒绝请求，导航例外不绕过来源网段、Host 或密码认证

### Requirement: 凭据迁移和重启恢复

系统 SHALL 仅通过已授权安全通道把会话重新加密迁移到 NAS；MUST 不记录明文 Cookie、令牌或密钥。

#### Scenario: NAS 重启

- **WHEN** 容器重启且独立密钥可读
- **THEN** 恢复草稿、同步记录、加密会话和原有自动续期能力

#### Scenario: 私有接口模块迁移

- **WHEN** 模块通过相对文件路径加载运行时协议配置
- **THEN** 私有部署包 MUST 包含所需同目录配置，模块迁移后可独立导入，配置保持仅所有者可读且不进入公开仓库或镜像

#### Scenario: 错误密钥或不安全文件

- **WHEN** 密钥权限不安全、是符号链接或无法解密
- **THEN** 拒绝加载，不回退到空连接伪装成功

#### Scenario: 再次登录

- **WHEN** 官方会话无法静默续期
- **THEN** 提示本人登录，通过受控加密迁移更新 NAS 会话，不向普通页面暴露凭据

### Requirement: 绿联项目生命周期

部署 SHALL 通过绿联 Docker 项目维护，持久数据与镜像分离，支持自启、健康检查、备份和回滚。

#### Scenario: 受限权限部署包构建

- **WHEN** 部署包目录为 0700、文件为 0600，镜像使用 UID 1000 运行
- **THEN** 镜像内程序、迁移文件、静态页面和健康检查脚本归运行用户所有且可读取；不能通过改为 root 或放宽凭据权限解决启动问题

#### Scenario: 升级与恢复

- **WHEN** 项目使用新镜像重建或从备份恢复
- **THEN** 保留数据与独立密钥，能恢复只读查询；自动测试不执行真实官方写入

#### Scenario: 首次证书信任

- **WHEN** 客户端尚未信任专用 CA
- **THEN** 提供公开 CA 文件与指纹让用户本人信任，不跳过安全警告，不把浏览器访问记为已验收
