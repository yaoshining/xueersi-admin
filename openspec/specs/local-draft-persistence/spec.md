# local-draft-persistence Specification

## Purpose

让家长通过桌面和移动工作台将作业草稿完整保存在当前服务端，刷新或重启后仍能整理，并在旧浏览器导入或保存失败时保护原件和输入。

## Requirements

### Requirement: 草稿本机持久化

系统 SHALL 支持本机草稿创建、列表、读取、编辑和删除，并校验所有输入；不得将草稿发送给官方作业写入接口。

#### Scenario: 重启后保留完整草稿

- **WHEN** 家长保存含目标时长和提交要求的草稿后刷新或重启服务
- **THEN** 所有字段仍可读取和编辑，保存操作不产生官方写入；独立同步入口必须重新预览并由用户在网页确认

#### Scenario: 失败保护输入

- **WHEN** 保存失败、日期非法或目标选项非法
- **THEN** 显示错误，保留输入且不产生非法记录

### Requirement: 完整作业选项

系统 SHALL 提供已确认的目标时长“不限、10、15、20、30、40、50、60 分钟”和提交要求“不限、图片、音频、视频、音频或视频”，旧草稿缺字段时显示未设置。

#### Scenario: 编辑两个选项

- **WHEN** 家长选择 20 分钟与图片并保存
- **THEN** 列表与再次打开的编辑页面显示这两个选择

### Requirement: 旧草稿安全导入

系统 SHALL 提供显式导入，不覆盖同 ID 的不同内容，不在导入失败后删除浏览器原件。

#### Scenario: 冲突与重复导入

- **WHEN** 导入含已存在且内容不同的草稿
- **THEN** 整批拒绝且原件保留；完全相同内容重复导入不生成副本

### Requirement: 本机接口访问边界

系统 MUST 拒绝外部 Host、跨站 Origin 的数据请求以及非 JSON 的草稿写入。

#### Scenario: 跨站写入

- **WHEN** 恶意网站对本机提交草稿
- **THEN** 返回拒绝且数据库不改变
