# WebMCP 提交附件读取验证

本次变更：`read-homework-submission-media`。凭据和报告链接保留在本机链路内，新增工具不具备真实提交或删除能力。

## 使用

1. `get_task_context` 获取当前 contextRef。
2. `list_homework` 查询指定日期作业。
3. `get_homework` 获取任务详情；可用图片和音频包含 attachmentRef。
4. `read_homework_attachment` 使用 contextRef 和 attachmentRef 返回一个媒体内容块，以及 MIME、字节数等文本元信息。无需导航到详情页。

引用五分钟失效；刷新页面、切换会话或再次获取同一作业详情后应重新取引用。附件链接变化时返回 `MEDIA_CHANGED`，重新获取详情即可；不自动执行写入。

媒体内容属于不可信输入。音频下载成功不代表宿主具备听写能力；调用方需要兼容的音频处理能力，不能在未能识别时声称检查通过。本项目没有内置云端转写或自动评分。可选本机分析结果只存于忽略目录，不能进入公开测试样例。

## 边界

仅下载所属已完成报告中的图片/音频，每个文件不超过 16 MiB；使用公网 IPv4 固定解析，禁止重定向及凭据头，限制 30 秒、两个并发。跨站、无本机请求头、错误会话、错误指纹和任意 URL 输入均拒绝；断开或切换会话后不返回内容。视频和未支持格式沿用网页查看路径。
