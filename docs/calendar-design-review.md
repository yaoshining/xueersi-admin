# 任务总览样式复查

日期：2026-10-17。范围为真实应用中的月历，不是宣传页面。

## 设计依据与技能适用边界

采用 design-taste-frontend 的信息层级、色彩比例、减少装饰和真实截图复查方法，保留 v3 的 sage 语义主题、Geist/中文系统字体和现有 shadcn Button/Card。技能本身注明不适用于 dashboard/app screen，因此不抽取营销页面方向，不新增图片、视频、大标题或八处滚动动效；本页也不冒充通过营销页 inspect.mjs 的图片/动效数量门槛。未抽签，无 seed 或重抽。

页面的具体材料：孩子、绑定 T6、本机草稿、每日安排、目标时长、提交要求、已完成、遗漏、月末核对、手机 +N 聚合、深浅主题、全屏。现有交互就是可展开的每日任务清单，视觉重点应服务核对，而不是装饰。

设计主张：把家长每日核对作业的过程变成一张安静但可扫读的月历。标题交代用途，统计显示整体进度，日期矩阵承载任务摘要，展开清单给出完整内容。

## 第一轮截图复查

- 统计数分散在四张同级卡片，和日格形成竞争；合并为一个平面统计区，用大小明确数字与标签关系。
- 大量空日反复显示“无任务”，淹没有任务的日格；视觉上去掉重复状态，日期链接的可访问名称仍保留。
- 摘要和状态字号过小，今天只靠边框区分；增大摘要及元信息，今天用实色日期标记，完成/遗漏同时使用状态文字和语义底色。

## 第二轮修正

- 保留桌面三条摘要和手机 +N；手机省略重复状态长文但保留完成比例、语义色和完整可访问名称。
- 完成比例使用真实计数与原生 progress 语义；空月份显示暂无任务，不伪造 0% 或 100%。
- 768px 补充七列和横向溢出检查。全屏的自然高度和纵向滚动保留。
- 日历线属于日期矩阵结构，不是装饰；保留必要分隔。轻微 hover 位移提供反馈，减少动态效果模式关闭。

## 第三轮复查

768px 截图发现学科标签被状态文字挤成纵排，新增失败断言后修复：中等宽度以学科和状态图标呈现，完整状态仍在日格和可访问名称中。最终两种主题复查未见标签折行或横向溢出。

## 验证方式

源文件运行技能 lint；应用视图通过 Playwright 的三种宽度和深浅主题截图进行人工复查，不使用宣传页面的奖项评分。截图仅包含合成账号和任务，保存在私有输出目录，不加入仓库。

保留的限制：七列手机日格无法完整显示长正文，仍需要 +N 在当前页展开。浏览器手机仿真不等于物理手机验收。
