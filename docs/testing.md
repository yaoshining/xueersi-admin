# 初始化测试记录

本记录只包含合成场景和结果摘要，不包含私人账号、设备资料或原始研究输出。

## TDD 过程

`bootstrap-monorepo` 首轮先编写契约、日期、适配器、API、存储和扩展导航的行为测试，再运行最小占位实现：6 个测试文件中 **19 项失败、2 项通过**。失败原因包括错误日期被接受、API 尚无路由、存储未实现、导航未限制目的地等。

实现后同一组测试 **21 项全部通过**。公开内容检查另有独立 Red 阶段：**2 项失败、1 项通过**，用于验证检测私有文件和常见凭据形态的规则。

端到端先对尚未渲染业务界面的页面运行，验证首页标题缺失；实现页面后验证健康状态、默认未连接、主动进入演示、错误状态和移动视口无横向溢出。构建阶段发现的依赖解析错误已修复，不计为业务 Red 证据。

本机最终结果：24 项单元／集成测试通过，4 项 Playwright 测试通过（三端构建、类型检查、lint、格式和 OpenSpec 严格校验均通过）。桌面浏览器已人工查看合成数据页面。首次公开提交的 [GitHub Actions](https://github.com/yaoshining/xueersi-admin/actions/runs/38944106580) 已在 Linux 上通过全部检查；本机使用 Node 24.22.0。初始化验收不包含真实学而思账号接入、作业提交、手机或学习机真机测试。

## 主要场景

| 范围         | 断言                                                                  |
| ------------ | --------------------------------------------------------------------- |
| 契约         | 字符串标识、有效日历日期、非空内容、已知科目、拒绝额外令牌字段        |
| 领域         | 北京时间跨日、非法时间拒绝                                            |
| 适配器和 API | 未连接时明确失败、不请求官方服务；演示有模式标记；未知 API 返回 404   |
| SQLite       | 关闭重开仍可读取；重复 ID 不覆盖；存储层校验                          |
| 扩展         | 只允许固定本机源，拒绝外部站点、伪造主机和脚本 URL                    |
| 公开检查     | 私有目录、数据文件、常见凭据形态与本机路径；检查 Git 索引而非仅工作区 |
| E2E          | 桌面及移动视口的默认状态、演示切换、错误呈现、禁用真实写入            |

没有通过固定快照或仅检查代码常量来替代行为验收。新增功能需先为实际行为写测试，再更新规格完成状态。

目标时长和提交要求依据用户截图及先前已保存的公开表单选项补齐；资料原件与私有运输实现不进入仓库。无官方作业写入、手机系统变更或远程部署。
