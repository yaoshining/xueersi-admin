# 草稿确认同步验证

## 范围

单条文字草稿，经预览和明确确认后创建作业。支持不限及 10、15、20、30、40、50、60 分钟；提交要求支持不限、图片、音频、视频、音频或视频。采用学科下的「其他」类型，不关联 AI 内容。

## TDD 与回归证据

先建立 OpenSpec `sync-drafts-with-confirmation`。新增服务测试在模块缺失时失败；新增页面测试在预览控件缺失时失败，再实现功能。结果落盘失败的测试先复现异常，再修复为「结果待核对」。

- `pnpm check`：79 项单元测试、格式、lint、类型、OpenSpec 与构建通过。
- `pnpm test:e2e`：60 通过、2 个按设备类型跳过。
- 服务测试覆盖确认前不写、取消、过期、草稿修改、异步预检期间修改、重复票据、并发和复制草稿防重、明确拒绝后重新确认、未知网络结果、结果落盘失败。
- 数据库测试覆盖发送途中退出后重启，保留重复保护并展示未知结果。
- 适配器测试覆盖只读阶段续期、写运输不携带 Cookie、写入失败不自动重放。
- HTTP 测试覆盖同源及请求头、严格确认结构、记录不包含凭据或确认密钥。
- 页面测试覆盖桌面/手机、深浅主题、完整字段、取消、确认、演示禁用、未知结果和旧草稿参数不串单。
- 私有协议映射另用合成数据覆盖 40 组时长/要求组合、5 种写运输响应；网络全部替身，代码与私密协议不公开。

## 实际验证边界

初次实现验收停在只读预检和测试草稿预览，未自动创建作业。之后获得用户对具体预览的明确授权，完成下述首次真实提交及设备侧验收。

未归档 OpenSpec，未提交或推送。公开仓库默认不配置私有创建运输。真实同步记录只存在本机 SQLite；不确定记录不自动清除或重试。

## 经用户确认的首次真实提交

2026-10-17 用户明确批准已预览的 15 分钟、提交图片的单条测试作业后，通过确认页发送一次。官方返回接受；随后重新只读查询官方列表，匹配到且仅匹配到一条同内容作业，目标时长为 15、提交要求为图片、学科和类型与预览一致。

云端创建与字段回读已验证。随后用户在 T6 上确认看到了该作业，目标时长和提交要求也正确。因此本次单条文字作业从网页确认、本机后端创建、官方列表回读到学习机显示的流程已完成验收。设备侧证据为用户实机核对，不是接口自动回执；不代表所有作业类型与提交形式均已实机验证。没有重复发送、修改或删除官方作业。凭据与原始验证资料未进入公开文档。

## 详情、删除和报告补充验证

- 补充 OpenSpec 后先运行新增删除服务/附件合约测试，得到缺少实现的失败，再实现并通过；月历统计和范围测试同样先失败再通过。
- 本轮 `pnpm check` 通过 93 项测试；`pnpm test:e2e` 76 通过、2 个按设备类型跳过。覆盖详情 15 分钟/图片、不限/未知值，删除预览取消及明确确认，持久防重、过期/切换账号/内容及完成状态变化，报告三种附件、过期/空/错误，以及整月范围/遗漏分类/全屏/日期下钻。
- 本机已只读核对实际月度统计、详情选项，实际图片已加载，音频成功加载播放并暂停。视频使用合成测试验证控件，目前没有实际视频样本验收证据。
- 删除仅验证只读预览和取消；未删除任何真实作业。官方删除最终副作用仍等待具体作业授权后的验收，不能把合成测试当作真实删除成功。
- 新增月历使用现有组件与语义主题实现类似 FullCalendar 的整月汇总布局，未引入 FullCalendar 依赖。
